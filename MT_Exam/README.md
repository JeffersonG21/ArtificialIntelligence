# Midterm — Credit Score Classification (Kaggle)

Classification of `Credit_Score` (*Good*, *Poor*, *Standard*) from a credit application dataset with errors, missing values and inconsistencies. Competition metric: ROC AUC.

## Contents

| File | Description |
|---|---|
| `MT_Exam.ipynb` | Full notebook: analysis, cleaning, baseline, experiments, final model and submission |
| `submission.csv` | Predictions uploaded to Kaggle (generated by running the notebook) |

## Solution

- **Cleaning:** text-to-number conversion, garbage categories → NaN, impossible outliers → NaN, repair of values with the mode/median of the same customer.
- **Features:** credit history in months, loan-type multi-hot encoding, financial ratios and customer-level averages.
- **Models:** Logistic Regression (baseline), KNN and Random Forest.
- **Final model:** Random Forest with tuned hyperparameters and a decision rule adjusted for class imbalance.

## How to reproduce

1. Install the dependencies (Python 3.10+):
   ```bash
   pip install numpy pandas scikit-learn matplotlib jupyter
   ```
2. Download the competition data from Kaggle and place it in a `csv/` folder next to the notebook folder:
   ```
   csv/
     X_train_Kaggle.csv
     y_train_Kaggle.csv
     X_test_Kaggle.csv
     sample_submission_credit.csv
   MT_Exam/
     MT_Exam.ipynb
   ```
   (or change `DATA_DIR` in the first code cell).
3. Open `MT_Exam.ipynb` and click **Run All**. `submission.csv` is generated at the end.

The seed `SEED = 42` fixes the splits and the models, so the validation results are reproducible.

## Results

| Model | Validation AUC |
|---|---|
| Logistic Regression (baseline) | 0.813 |
| KNN (k=50) | 0.869 |
| Random Forest (tuned) | 0.921 (probabilities) / 0.871 (labels, α = 1) |
